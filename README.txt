ENERO, JUNTOS. — VACACIONES EN FAMILIA 2027

Sitio: https://unmatrixlab.github.io/vacaciones-familia-enero-2027/
Proyecto: https://github.com/unmatrixlab/vacaciones-familia-enero-2027

Contenido:
- palace/: dossier RIU Palace Punta Cana, incluidos sargazo y parque acuático.
- dominicana/: comparador regional con preferencia RIU.
- investigacion/: investigación original de destinos y alojamientos.

Sitio estático: HTML, CSS, JavaScript y fotografías locales. Sin dependencias,
servidor de aplicación, cuentas de usuarios ni claves de acceso.
GitHub Pages publica desde la raíz de la rama main. El archivo .nojekyll
mantiene los archivos estáticos sin procesamiento Jekyll.

Para verlo localmente: abrir index.html o ejecutar python3 -m http.server 8000
en esta carpeta y visitar http://localhost:8000.

Investigación: 7 octubre 2026. Precios y disponibilidad son observaciones o
estimaciones fechadas; no reservas confirmadas. Las fotografías conservan sus
fuentes y créditos en cada informe. No se otorga una licencia nueva al material
de terceros. Los datos de trabajo y borradores no forman parte de este sitio.
